# Chess Coach

A personal chess coach for a beginner: play against Stockfish, get plain-language explanations, and let the app learn your habits. Runs entirely on your device (installable, works offline).

## Enable GitHub Pages

1. Push this repo to GitHub as `jasonfr0/Chess-App`.
2. In the repo go to Settings, Pages, and set Source to "GitHub Actions".
3. Pushing to `main` (or running the "Deploy to GitHub Pages" workflow by hand) builds, tests and publishes the app at `https://jasonfr0.github.io/Chess-App/`.

If the repo is private and your plan does not include Pages, Cloudflare Pages or Netlify work too (build command `npm run build`, output `dist`; change `base` in `vite.config.ts` to `'/'`).

## Install on Android

1. Open `https://jasonfr0.github.io/Chess-App/` in Chrome and let it finish loading once.
2. Tap the menu (three dots), then "Add to Home screen" (or "Install app").
3. Launch it from the home screen. After the first load it works with no connection; the coach then uses built-in explanations.

## Add your API key

Optional. Without a key the coach uses built-in explanations (shown with a "coach offline" dot). To get Claude-written explanations, open the Settings tab, paste your Anthropic API key, pick a model and tap the test button. The key is stored only on your device and sent only to Anthropic.

## Development

```
npm install      # also copies Stockfish into public/stockfish/
npm run dev      # http://localhost:5173/Chess-App/
npm test         # unit tests
npm run e2e      # builds, then runs Playwright against vite preview
```

Icons are generated by `node scripts/make-icons.mjs` (output committed in `public/icons/`).
